# Code of conduct

This is a small project run in spare time. These few rules cover the issue
tracker, pull requests, discussions and anywhere else the project is talked
about.

## What is expected

- Be civil. Disagree with the idea, not the person.
- Assume the other person means well and is short of time, as you are.
- Stay on the subject: this tool, how it works and how to make it better.
- Say so when you are wrong, and let others do the same without fuss.

## What is not accepted

- Insults, harassment, threats, or picking on someone for who they are.
- Publishing anyone's private information.
- Asking for help getting specific copyrighted works, or posting links to
  them. The tool is for audiobooks its user is legally allowed to acquire,
  and so is this project's space.
- Posting API keys or other secrets, your own or anyone else's.

## What happens

A maintainer may edit or remove anything that breaks these rules, close or
lock the thread, and block people who keep at it. There is no appeals
process; this is one person's project. If something was handled badly, say
so calmly and it will be looked at again.

## Reporting

For anything you would rather not raise in public, use the private report
form linked from [SECURITY.md](SECURITY.md); it reaches the maintainer and
nobody else.
